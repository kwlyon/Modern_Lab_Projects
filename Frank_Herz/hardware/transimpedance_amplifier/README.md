# Frank–Hertz transimpedance amplifier

This is the separate current-to-voltage amplifier for the Frank–Hertz
experiment, **not** the Arduino acquisition shield. The original Eagle project
was `Box/eShop/Eagle/Eagle Projects/Modern Lab/Frank_Hertz`.

- [`Frank_Hertz_Transimpedance_Amplifier.sch`](Frank_Hertz_Transimpedance_Amplifier.sch) — Eagle schematic.
- [`Frank_Hertz_Transimpedance_Amplifier.brd`](Frank_Hertz_Transimpedance_Amplifier.brd) — Eagle board.
The Eagle schematic and board were copied byte for byte; only their filenames
changed. Fabrication outputs remain in the original Eagle project. Run ERC/DRC
and generate fresh Gerbers from this board before ordering boards.
