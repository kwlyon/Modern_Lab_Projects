# Modern Lab Projects

This repository collects three laboratory data-acquisition projects. Each project
keeps its own source, firmware, documentation, and setup instructions.

| Project | Contents |
| --- | --- |
| [Frank_Herz](Frank_Herz/README.md) | Franck–Hertz acquisition software and differential Arduino shield firmware |
| [SerialPlotter](SerialPlotter/README.md) | Original serial plotter and acquisition shield design |
| [SerialPlotter_V2](SerialPlotter_V2/README.md) | Two-channel voltage strip recorder and its Arduino sketch |

The projects were imported with unsquashed Git subtree merges. Their original
commits remain in this repository's history. Frank_Herz release tags are retained
under `Frank_Herz/v...` names so they remain distinct from future tags for other
projects.

See each project's README for build, calibration, and hardware instructions.
Frank–Hertz Windows downloads and firmware attachments are available on the
[releases page](https://github.com/kwlyon/Modern_Lab_Projects/releases).
